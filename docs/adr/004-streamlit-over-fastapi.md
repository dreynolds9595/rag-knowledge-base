# ADR 004: Streamlit for UI

## Status
Accepted

## Context
The project needed a demo UI and free hosting.

## Decision
Use Streamlit with Streamlit Community Cloud.

## Consequences
**Positive**: Zero-cost permanent hosting, fast iteration, built-in widgets.
**Negative**: Less control over the frontend than React; not suitable for production APIs.
